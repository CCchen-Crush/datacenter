# 审稿意见：计及跨事件算储联合恢复的数据中心综合能源系统连续需求响应优化调度

> 模拟期刊审稿（2026-10-21）。所有“复核数据”均由本仓库代码在 GNU Octave 8.4 + glpk 下补跑得到；对应的修改进度见 [`修改进度.md`](修改进度.md)。

**审稿结论：大修（Major Revision）。**

**优点：** 选题新、切入点清楚（两类恢复状态争用同一条恢复通道）；数据与代码公开；结算规则贴合《江苏省电力需求响应实施细则》；有机理分析也有命题。

**主要风险：** 用仓库代码补做复核后发现三类问题审稿人一定会抓：
1. 有两个主要结论依赖作者自设的考核参数；
2. 对比基准没有调优；
3. 评价口径存在可被策略性利用的漏洞。

---

## 一、必须解决的关键问题

### 1. 反弹降低和日前承诺两个结论，几乎完全由自设的“反弹考核”决定（最严重）

- **现象：**
  - 江苏细则里没有反弹考核，3 元/kW·次是作者自设。
  - 把它置零重跑后，三种策略的最大反弹完全相同，都是 6.52 MW，恰好等于“并网上限 − 基线”。
  - 同时，耦合日前评估给出的承诺变成 8.18/7.98/7.90 MW，与单事件评估完全一样。
- **能站住的结论：** 兑现率优势仍在（统一 6 MW 承诺下 JR 100%，IR-O 90.6%），综合成本仍降低 11.3%。
- **影子价格佐证：** γ=1.10 时，事件间隔内并网约束的影子价格为 0；真正起约束作用的是反弹考核，其影子价格约 3000 元/MWh。即标题强调的“并网容量约束”在基准算例里对联合策略基本不起作用。
- **建议：**
  - 把反弹成本落到真实机制上（如两部制最大需量电价、电网净负荷二次峰值、同时率峰值计费），或把它当作政策参数，画出“兑现率—反弹—成本”帕累托前沿；
  - 结论改写为“联合恢复让反弹变得可定价、可调控”，不要写成“天然降低反弹”；
  - 补做 $c^{\rm rb}=0$ 时的影子价格分析，展示物理并网约束本身形成的通道竞争。

|---|---|---|---|---|---|
| 0 | 8.18/7.98/7.90（耦合=单事件） | 56.4% / 6.52 | 71.7% / 6.52 | 100% / 6.52 | −21.2% |
| 0 | 6/6/6 | 70.2% / 6.52 | 90.6% / 6.52 | 100% / 6.52 | −11.3% |
| 3 元/kW | 4.43/5.49/7.90 | 73.6% / 6.52 | 92.9% / 6.45 | 100% / 5.30 | −13.9% |
| 3 元/kW | 6/6/6 | 70.2% / 6.52 | 88.0% / 6.45 | 100% / 6.06 | −15.7% |

### 2. 对比基准未调优，兑现率提升的幅度不稳

论文消融实验已显示 IR-O 的固定分摊比例 α=0.9 时可达 100%。补跑 20 日蒙特卡洛：

| IR-O 分摊比例 α | 兑现率 | 三次全有效的天数 | JR-S 相对它：兑现率 / 最大反弹 / 综合成本 |
|---|---|---|---|
| 0.41（论文采用） | 86.4% | 65% | +12.7 个百分点 / −37.8% / −15.7% |
| 0.7 | 92.6% | 80% | +6.6 个百分点 / −36.5% / −11.6% |
| 0.9 | 95.9% | 95% | **+3.2 个百分点** / −36.8% / −8.6% |

- **建议：**
  - α 用日前信息优化确定（不能用事后信息）；
  - 增加基准：①“联合但只看当前事件”（逐事件联合，代表现有单事件 DR 调度方法），用来分离跨事件远见的作用；②“价格协调的独立恢复”（IT 侧只接收一个恢复通道价格信号）；③文献[9][12]的方法；
  - 每种策略各用自己的日前承诺（常规做法 = 单事件承诺 + 独立恢复），消除“承诺是按 JR 能力定的”这一质疑；
  - 标题和摘要里的数字以最强基准为准。

### 3. 评价口径有三处漏洞

- **事件前抬升负荷：** 14–17 时各优化策略比基线平均高 2.50 MW（最高 +3.32 MW），其中高温日本身的基线误差只占 1.09 MW，其余来自把储能留满（不做分时放电），且发生在分时电价峰段内。
  - 建议补充“相对同日不响应时的真实削减”与“事件前抬升量”两个指标，并对“事件前 2 h 负荷作基线”（江苏快上快下口径）做敏感性分析（参考基线操纵文献 Chao 2011）。
- **反弹窗口被“卡点”：** JR-S 在 22–24 时把购电功率精确压在基线上，代价是内燃机满发 6.0 MWh（不响应时 0.38 MWh）；窗口一结束（24 时）就比基线高 1.9 MW。
  - 建议改用与窗口无关的指标（事后 6 h 回补电量、最大爬坡、对晚高峰的贡献），并计入碳排放。
- **评价期末状态不一致：** 各优化策略在评价期末都留下约 3000 GPU·h 未到期积压，规则策略和不响应方案为 0。应加终端积压约束，或按价值折算后再比较成本。

### 4. “场景 MPC”的贡献证据不足

- 与确定性 MPC 相比只多 0.33 个百分点、反弹低 13%（成本 −0.1%）。连续响应最主要的不确定性——下一个事件会不会来、何时来、持续多久——没有建模（三个事件都在日前已知）。
- **建议：** 建模事件发生的不确定性，加入“就绪储备”，给出 VSS/EVPI；或把卖点改成“降低兑现波动”（独立恢复标准差 14%–17%，联合恢复约 1.3%）。
- **统计：** 运行日扩到 ≥40–60 个，给出置信区间与配对检验；补价格敏感性（补贴单价 1–3 元/kWh、偏差考核系数 κ）。

### 5. 理论部分需要从“数值验证的上界”升级为定理

- 命题 1 在 80 个工况中 47 个紧，但间隔很短时偏松（例：上界 0.98，实际 0.73）。
- **建议：** 给出完整证明和紧性条件；用简化模型推出最小恢复间隔 τ* 的闭式解与“独立恢复的效率损失”上界；把影子价格中观察到的规律写成结构性结论（等边际价值原则：储能边际价值约 4156 元/MWh，C1 积压边际成本 4.31 元/GPU·h ≈ 4.2 元/kWh 当量；C3 仅 3.13 元/GPU·h，故优先携带）。

### 6. 模型真实性与文献定位

- **负荷数据：** PAI 为 2020 年轨迹（早于大模型时代），建议加用 Acme 大模型开发轨迹（Hu 等，NSDI 2024）；用作业级仿真检验流体模型误差（检查点开销、整组调度粒度、最短暂停）；补充启停功率阶跃与爬坡约束（Choukse 等 2025）。
- **调节手段：** 补充 GPU 功率封顶（Acun 等，ACM e-Energy 2026：18%–55%），其“恢复欠账”与暂停不同。
- **冷却方式：** 新建 AI 数据中心多为液冷，制冷系数提高后 DR 的冷却放大效应变小，需做敏感性。
- **综合能源系统作用偏弱：** 去掉蓄冷成本只升 3.2%；内燃机峰段本就满发，其真正作用是事后（22 时后）的“恢复通道提供者”（用燃气换通道，需计碳）。要么强化多能耦合（机房热惯性、余热供暖、内燃机作为恢复资源），要么收窄标题。
- **文献：** 补 2025–2026 新工作（Williams 等 2026；Du 等 2026；Acun 等 2026；Evans 等 2022 TSG“恢复保证”最接近，需明确区分：本文是异质双状态——时限约束、近乎无损的虚拟储能 + 有损物理储能——跨事件争用恢复通道）。

## 二、提升创新性的方向（建议选 1–2 个做深）

1. **跨事件可交付能力域：** 把“单个承诺值”升级为可行承诺向量集合，并给出便于报价的内近似（虚拟电池/多面体）；独立恢复的损失即该集合的收缩。适合 TPWRS/TSG。
2. **“恢复欠账”统一框架：** 按事后欠账给调节手段分类（暂停：欠账=全部工作量；功率封顶：欠账<工作量；推理量化：无欠账有质量损失；储能：欠账/效率；内燃机：无欠账有燃料与碳成本），推出统一恢复优先指数，把“双状态”推广为多资源恢复理论。
3. **影子价格引导的分布式协同：** IT 调度与设施能管只交换“恢复通道价格”（或 ADMM 迭代），验证不共享全部信息能拿回多少联合恢复收益。工程价值高。
4. **“感知恢复”的需求响应机制设计：** 电网侧安排事件间隔时考虑数据中心恢复（双层模型）；改进结算（按日累计结算、恢复窗口、反弹定价）。复核中发现间隔很短时最优策略会故意只交付 80% 以保住三次有效——这本身是结算规则问题的证据。
5. **事件不确定下的“就绪储备”：** 把“为可能到来的下一次事件预留的能力”定义为类似备用的产品，用机会约束/分布鲁棒优化求解。

## 三、次要意见

- 补符号表、算法流程伪代码、计算时间表；摘要数字只保留最强基准下的结果；统一 GPU·h 与 MWh 的换算口径；说明“双状态”实为 5 维状态向量。

## 四、修改优先级

| 优先级 | 内容 | 工作量 |
|---|---|---|
| 1 | 反弹考核敏感性/帕累托分析，基准 α 调优，修三处评价口径（问题 1–3） | 1–2 天 |
| 2 | 事件不确定性 + 扩大样本统计（问题 4） | 2–3 天 |
| 3 | 能力域或分布式协同，任选一个做深（创新方向 1 或 3） | 1–2 周 |
| 4 | 闭式解与定理化（问题 5） | 1 周 |
