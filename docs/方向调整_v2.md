## 2 新增四块

### A 替代曲线（系统级洞见，对标范文 Fig. 17）

- **电池扫描**：S2（30 min 间隔），电储能 0/3/6/9/12 MW（2 h 配比），二分法求 JR-D 与最强独立基准 IR-O* 的 $C_{0.95}$；6 MW 基准配置另求 JR-M。读出“独立恢复要多配多少 MWh 电池才能追平 JR-D”，按 0.6 元/Wh 系统造价折成投资。
- **接网扫描**：γ = 1.00/1.05/1.10/1.20/1.30（1.10 为基准，在电池扫描里），读出等效节省的接网容量（MW）。
- **图**：替代曲线 + 上下镜像柱（联合恢复 ↔ 等效电池 MWh、接网 MW）。
- **代码**：`experiments/exp20_capacity_configs.m`（`E20_SET='bess'|'gamma'`），`src/capacity_search.m`（二分法，失败天数超过 ρ 允许值即提前停止）。

### B 分布鲁棒可靠容量承诺（方法辨识度，命题 3）

- **数据**：在日前场景池的 20 个历史工作日上做闭环回测（`experiments/exp18_history.m`，`src/history_ctx.m`），得到每种策略每天能足额交付的最大承诺 $\xi_d$。
- **方法**：1-Wasserstein 球 $\mathcal B_\varepsilon(\hat P_N)$ 包住 $\xi$ 的经验分布，求满足 $\inf_{Q\in\mathcal B_\varepsilon}Q(\xi\ge C)\ge\rho$ 的最大承诺 $C^{DRO}_\rho(\varepsilon)$。
- **命题 3**：一维情形按排序精确求解（最坏分布把离 $C$ 最近的样本优先搬到 $C$ 以下）；$\varepsilon=0$ 退化为样本序统计量（SAA）；$C^{DRO}$ 随 $\varepsilon$ 单调不增，能力分布越集中、裕度越大越不敏感。半径用测度集中界或留一交叉验证选取。
- **图**：日前预测足额率对样本外实际足额率的校准图（SAA 与 DRO 对比）。预期 JR-D 能力分布集中、鲁棒化几乎不降；IR-O* 分散、鲁棒容量大幅下降 → “联合恢复让承诺容量更可信、可认证”。
- **不照搬**两阶段 DRO + C&CG：其第二阶段是完美追索，衡量物理能力，与本文“物理能力评估超报”的核心发现矛盾。
- **计算**：鲁棒容量在 Python 中计算（`tools/paper_numbers.py`、`tools/plot_paper.py`），不改 MATLAB 模型。

### C 让综合能源进入恢复故事

- **桑基图**：事件间隔和事后 2 h 内恢复能量的来源（并网余量、燃气机组增发、光伏、蓄冷替代电制冷）与去向（补算、电池回充、蓄冷回充），IR-O* 对 JR-D，对标范文 Fig. 13。由典型日时序（`ts15_*.csv`）直接计算。
- **设备贡献**：分别去掉燃气机组、蓄冷、吸收式制冷（以及全部去掉），看 JR-D 的 $C_{0.95}$ 下降多少（`E20_SET='ies'`；`ctx_with_par` 新增 `gt_on`、`ac_on` 开关）。
- **定位**：综合能源是恢复通道的提供者——燃气机组拓宽通道，蓄冷把制冷负荷移出通道。
- 可选（优先级最低）：阶梯碳价下的可靠容量–碳排放权衡。

### D 用户侧帕累托与图扩充

- 用 exp12 现成数据画“可靠容量–算力服务质量”帕累托前沿（平均附加完成时间、SLA 余量占用），对标范文 Fig. 15。

## 3 另外补齐

- **IR-O 事后最优分摊上界**（`experiments/exp19_hindsight.m`）：每个测试日逐个试分摊比例，只要有一个能足额就算该日可交付；得到任何静态分摊的可靠率上界。
- **暂停/恢复开销稳健性**（`E20_SET='overhead'`）：每推迟 1 GPU·h 额外产生 2%/5% 工作量（同截止时间，只在仿真器里加，控制器只能通过状态反馈看到），确认 JR-D 相对 JR-M、IR-O* 的容量优势不变。参数 `par.it.overhead`，默认 0。
- **闭环两事件可靠可行域**：batch3 的 `reg1–reg4`（已在运行）。

## 4 不做的事

- 不加 LSTM 预测（旧版完美预测对照表明差距来自控制结构，预测不是瓶颈）。
- 不做两阶段 DRO + C&CG（理由见 B）。
- 不做多数据中心空间迁移、全寿命周期规划（下一篇的题目）。
- 暂不加机房热惯性作为第三类欠账（要改模型并全部重跑，风险大于收益）。
- 单站点、只有夏季、以两事件为主：写进局限即可。

## 5 调整后的贡献（仍为三条）

1. 跨事件异质恢复模型 + 命题 1、2。
2. 可靠可交付容量及其分布鲁棒承诺 + 命题 3；指出完美追索两阶段口径会超报可交付容量。
3. 联合恢复框架与验证：协调价值与预见价值的分解、电池与接网容量的替代曲线、综合能源设备的贡献，以及适用条件。
